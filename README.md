# VOLOKNOSTARS

## Каталог Ozon

`catalog-ozon.js` содержит подтверждённые данные 15 карточек магазина VOLOKNOSTUDIO на 3 ноября 2026 года: обновляет 10 комплектов и добавляет 5 новых товаров без цены с кнопкой «Уточнить цену». Цены 34 исходных товаров сохраняются. Похожие модели IP67 и IP68 не объединены.

Источники и ограничения зафиксированы в `ozon-import.json`. Перенос пока неполный: доступны основные фотографии и краткие характеристики, но не весь каталог из 46 товаров, полные галереи и описания. Для завершения нужна выгрузка Ozon Seller. Фотографии загружаются напрямую с CDN Ozon, их доступность зависит от внешнего сервиса.

Статический сайт: HTML, CSS и JavaScript без сборки.

## Vercel

Импортируйте этот репозиторий, выберите Framework Preset: Other, корневую папку `./`. Команду сборки оставьте пустой. Основной файл — `index.html`.

В метаданных указан адрес `https://voloknostars.vercel.app/`; назначение домена выполняется отдельно в Vercel.

Изображения загружаются с внешних сайтов. Формы используют Web3Forms; отправка заявок при подготовке не проверялась. Бонусная игра временно отключена: исходный файл `game.html` отсутствует.
